# Zenddy Winkeldashboard

Next.js-webapp waarmee een winkel de status van hun Zenddy-bestellingen kan volgen.

## Starten (lokaal)

```bash
npm install
cp .env.example .env   # NEXT_PUBLIC_API_URL moet naar de draaiende backend wijzen
npm run dev            # start op http://localhost:3000 (of een andere poort als 3000 al bezet is)
```

Zorg dat de backend (`../backend`) al draait, anders krijg je een foutmelding op de pagina.
